# What jam/off.sha256 covers

`jam/off.sha256` holds only the package hash of the DUELL_TIDE=0 build (`jam/check_off.sh` compares the first 64 characters).
This file keeps the narrative that used to follow the hash on the same line: what the last hash update included. A new always-on
fix that changes the hash adds its reason here (and in its commit message), newest first.
