## changelog
### 1.0.0-b12
- **Names (design overhaul part 4):** the firmware package is `tide-beta-<version>.fwsc` (a release `tide-stable-<version>.fwsc`), named from `TIDE_VERSION`, the same name the GitHub releases and the installer use; `tide-latest.fwsc`, `tide-version.json`, `release-tide-<version>/` and `tide-<version>-app.bin` replace the `duell-` ones. `TIDE_VERSION` is `1.0.0-b12` (it still said `1.0.0-b9`, so ABOUT and the emulator header showed b9). Backups made by `jam/jam_dev.py` are `TIDE-backup-*.json` / `TIDE-safety-backup-*.json`, the emulator's saved data `tide-flash-*.bin`, the editor's safety copies `tide-safety-copy-*`. Unchanged on purpose: the file formats inside (`duell-backup`, `duell-patches`, ... so older files still load), the "DUELL 1.1" the unit reports over USB (the installer reads it), the USB product name, and the credit to DUELL (OSCILL/R) and Felucca (Hügelton Instruments).
