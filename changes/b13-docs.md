## changelog
### 1.0.0-b13
- **Footer (owner's pick, 14 November):** while a pass is recording, the REC mark is the red dot only, so the patch name fits and stops scrolling (the "#131 clipped" the owner saw was the name scrolling because the mark took its room). PR 104.
- **Live assist, two fixes from the b13 bug hunt:** a 2- or 4-bar answer plays in step with the take, also on a part whose loop is shorter (before, it landed out of step for good; PR 107); loading a multi while REC is armed starts the pass again on the new music (before, an answer nobody asked for overwrote the new multi's part, and UNDO brought back the old patterns; PR 108).
- **Sounds tuned against the owner's sample libraries (14 November):** 57 factory sounds got width on keys and stabs, a front on flat leads, darker basses, cleaner FM and a 3 ms attack on pads and chords (PR 110); 15 multis got the kick room by the pattern (M03, M05, M11, M15), M04 rubbed out, register splits (M07, M13), levels (M13, M14, M16, M17, M18, M21, M23) and cleaner FM / detune (M02, M11, M19; PR 111). Four of those changes were taken back or trimmed after the full run found them out of the window (DUB BLIP's attack, BREADBIN, ELASTIC BASS, the lifts of M14, M16 and M23; PR 112).
- **Five genre multis for the gaps in the set (PR 119):** M05 HSE CHICAGO (classic house), M06 ELEC CRISP (IDM), M20 DUB ROOTS, M22 ELEC OUTRUN (synthwave) and M26 AMB JUNGLE (atmospheric drum and bass) replace the five weakest house / tech multis at the same numbers. Patterns are written from the genre research and built from the new real sounds.
- **Credits for the human-made sounds:** the replaced sounds come from Felucca's own engine presets, Clipper's REESE / MOOG BASS / STRINGS (GPL-3.0), the Aquanode DX7 banks (CC0) and YM2612-Dexed-Presets (MIT, Nick Culbertson); the sources and licences are in NOTICE.md.
