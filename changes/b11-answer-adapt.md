## changelog
### 1.0.0-b10
- **New (ANSWER follows the mode, owner 13 November):** turning ANSWER or ANSWER ON while a take stands now makes the answer again from that take with the new value, on the next bar line (PLAY running or not), so a melody you have played adapts when you swap the mode. The take's own seed is used, so the same value always gives the same answer; it is not a history step, so OCT- + PRESETS still goes back to before the take. ANSWER OFF (or ANSWER ON OFF) gives the other part its old pattern, grid and ARP mode back on the bar line. Turned several times before the bar line, the last value is the one that lands. An answer you have edited since is left alone. While REC is armed the change forces the next pass's answer to be made again. Device build +748 B flash.
