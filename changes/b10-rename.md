## changelog
### 1.0.0-b10
- **Changed (the product is called TIDE):** the name is TIDE everywhere a player or visitor sees it, no longer "DUELL with TIDE". The editor, backup page, installer, emulator, landing page, cheat sheet and issue forms say TIDE; the update screen's footer reads TIDE; ABOUT and the splash credit carry the one attribution line "built on DUELL (OSCILL/R) and Felucca (Hügelton Instruments), GPL-3.0"; the installer says "Detected: TIDE running" for a TIDE unit; backup files are `TIDE-backup-<date>.json` (the editor reads the old `DUELL-backup-` files too). Release packages are named `tide-stable-X.Y.Z.fwsc` and `tide-beta-X.Y.Z-bN.fwsc`; `releases.py`, the site build and the Pages workflow read both these names and the older `duell-tide-...` ones, in the same order by version. LICENSE, NOTICE.md and CREDITS.md keep every notice (only their headings changed). Unchanged on purpose: the USB product name, the editor protocol's version string (`DUELL 1.1`, so every unit and every old backup keeps working), the `DUELL_*` macros, the repository name, and the pictures (the cover, the editor header) until they are redrawn.
