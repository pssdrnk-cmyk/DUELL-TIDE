Back up (recommended)

BACK UP

Reads the unit and saves a file with your current sounds and settings to this computer. Nothing is written to the FM-1. It needs a firmware that supports backups (Felucca, DUELL or TIDE). The official M-VAVE firmware cannot be backed up from this page.

The file holds every patch, the settings and the music of both parts; from DUELL 0.2.14 on also the MULTIs and the PATTERN slots, and the user wavetables. An older firmware cannot save the MULTIs and PATTERN slots: the message after the backup says so. A backup is restored in the editor (its Backup page).

    Connect

    Connect the FM-1 by USB and switch it on. Close other programs that use MIDI (a DAW, another browser tab). Chrome will ask to allow MIDI with SysEx: allow it.

    Install

    INSTALL TIDE

    The page checks what your FM-1 runs now and sets the box below for you. You can always tick or untick it yourself.

    Erases your settings (theme, scale, MIDI channels, favourites), the autosave, your patches, your multis and your patterns. The factory sounds, multis and patterns come back. This cannot be undone: back up first. Left off, your saved data stays and the unit comes back as you left it.

    Do not switch off or unplug the unit while it installs. On a unit that runs TIDE or DUELL the page first saves a backup file to your downloads and stops if that fails (the Backup page restores it).

    If it stops: replug the cable and press Install again, with the same build chosen. The FM-1 stays in update mode until the write is finished, and the page resumes it.

    Go back to the official firmware

    RETURN TO OFFICIAL FIRMWARE

    This writes the official M-VAVE firmware back. TIDE will be removed. Keep the cable connected until DONE.

    Download the official FM-1 firmware (FM-1.fwsc, V15) yourself from M-VAVE's download page: m-vave.com/download. This project does not host or redistribute M-VAVE's files. Select the unmodified file here; the page checks it in your browser (it is never uploaded) and only accepts V15.

    TIDE music and sounds cannot be opened by the official firmware.

    Go back to plain DUELL 1.1

    PLAIN DUELL 1.1 (OSCILL/R)

    To leave TIDE and run the original DUELL 1.1, use the Install page on OSCILL/R's DUELL site. This page does not host their package. Save a backup here first. Plain DUELL does not read a patch whose End B morphs an FM6 sound (it shows the factory sound and drops that patch at its next save). Details: RECOVERY and Known limits.
