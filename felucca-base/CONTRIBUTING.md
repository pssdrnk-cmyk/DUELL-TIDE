# Contributing to DUELL

> This is OSCILL/R's file for plain DUELL, kept as it was. **For DUELL with TIDE (pssdrnk's fork) read [../CONTRIBUTING.md](../CONTRIBUTING.md)**; the issue links below go to OSCILL/R's project.

Thanks for helping! To keep things easy to follow, please use the right place:

| What | Where |
|---|---|
| A bug you can reproduce | [Issues](https://github.com/oscillr/DUELL/issues/new/choose), bug report form: one issue per bug |
| A feature idea or request | [Issues](https://github.com/oscillr/DUELL/issues/new/choose), idea form: one idea per issue (no promise it will be added) |

## Reporting a bug

Please include the DUELL version (hold HOME > ABOUT), your computer's OS and browser if the editor or
installer is involved, the steps to reproduce it, what you expected and what happened. A photo or a short
video helps.

## Pull requests

Pull requests are welcome, including AI-assisted ones, with the same bar for all:

- keep it small and focused on one thing;
- make sure you understand the change and can explain it;
- test it on a real FM-1;
- run `tests/run_tests.sh` (see [BUILDING.md](BUILDING.md); in the DUELL with TIDE fork: `sh host_tests.sh <group>`, see [../docs/DEVELOPING.md](../docs/DEVELOPING.md));
- new files carry the GPL-3.0-only SPDX header.

By contributing you agree that your contribution is licensed under GPL-3.0-only.

The web editor and installer live in [Felucca-WebApp](https://github.com/hugelton/Felucca-WebApp).
